# Company Sales Performance Analysis

This project provides a comprehensive analysis of company sales performance using a sample financial dataset, visualized in a Power BI dashboard.

## Visualizations

The dashboard includes several key visuals to explore the data:

* **Count of Units Sold by Discount Band**: A bar chart showing the relationship between discount levels (High, Medium, Low, None) and the total number of units sold. It indicates that higher discounts correlate with a greater volume of units sold.
* **Sum of Profit by Product and Discount Band**: A clustered column chart that breaks down the total profit for each product based on the discount strategy applied. This helps identify which products are most profitable under different discount conditions.
* **Profit Breakdown by Product and Segment**: A detailed pie chart illustrating the average profit and sum of units sold, categorized by both product and customer segment.

## Data Source

The analysis is performed on the `Financials.csv` dataset. This file contains transactional sales data, including products, units sold, profit, sales figures, and discount bands.

## How to Use

1.  **Explore the Dashboard**: Open the `Power BI - Company Sales data visualization.pdf` to see static images of the report's key visuals.
2.  **Interact with the Data**: To fully explore the project, open the corresponding `.pbix` file in Power BI Desktop.
3.  **Review the Raw Data**: The `Financials.csv` file is available for inspection or use in other analytical tools.

## Tools Used

* **Power BI**: For data modeling, analysis, and visualization.
* **CSV**: The format for the raw dataset.
