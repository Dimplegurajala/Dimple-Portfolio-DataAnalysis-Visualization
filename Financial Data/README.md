# Comprehensive Sales & Profitability Analysis using Power BI & Tableau

This project provides a multi-faceted analysis of company sales performance using a sample financial dataset. By leveraging both Power BI and Tableau, this repository offers a comprehensive look at key business metrics, including profitability, discount strategy effectiveness, and sales distribution across various segments and countries.

## Dashboards & Visualizations

This project features two distinct dashboards, each built with a leading BI tool to showcase different analytical perspectives.

### Power BI Dashboard

The Power BI report focuses on a granular breakdown of sales and profit metrics.

* **Count of Units Sold by Discount Band**: A bar chart showing the relationship between discount levels (High, Medium, Low, None) and the total number of units sold, indicating that higher discounts correlate with a greater sales volume.
* **Sum of Profit by Product and Discount Band**: A clustered column chart that breaks down total profit for each product by the discount strategy applied.
* **Profit Breakdown by Product and Segment**: A detailed pie chart illustrating financial metrics categorized by both product and customer segment.

### Tableau Dashboard

The Tableau workbook offers a highly visual and interactive exploration of the data, focusing on correlations and geographic trends.

* **Discounts vs. Sales**: A dashboard exploring the direct relationship between discounts offered and the resulting sales figures.
* **Profit vs. Discounts**: An analysis of how different discount levels impact overall profitability.
* **Profits and Sales Across Countries**: A geographic map that visualizes sales and profit distribution across the globe to identify key markets.

## Data Source

All analyses are performed on the `Financials.csv` dataset. This file contains transactional sales data, including products, units sold, profit, sales figures, and discount bands.

## How to Use

1.  **Explore Static Reports**: Open the `Power BI - Company Sales data visualization.pdf` and the `.png` image files to see static examples of the dashboards.
2.  **Interact with the Data**:
    * To explore the Power BI report, open the corresponding `.pbix` file in Power BI Desktop.
    * To explore the Tableau workbook, open the `.twbx` file in Tableau Desktop or Tableau Public.
3.  **Review the Raw Data**: The `Financials.csv` file is available for inspection or use in other analytical tools.

## Tools Used

* **Power BI**: For data modeling and detailed dashboarding.
* **Tableau**: For interactive visualization and geographic analysis.
* **CSV**: The format for the raw dataset.
